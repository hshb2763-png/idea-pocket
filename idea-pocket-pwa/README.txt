IDEA POCKET — SUPABASE 동기화 버전

포함 기능
- 이메일 회원가입 및 로그인
- 로그인 상태 유지
- PC Ctrl+V 이미지 붙여넣기
- 휴대폰 사진 선택
- Supabase Storage 이미지 저장
- Supabase Database 메모 및 상태 저장
- PC와 갤럭시 동일 데이터 동기화
- 왼쪽 보류 / 오른쪽 선택 / 위 사용 완료
- 보관함 상태 변경 및 삭제

GitHub 업데이트
1. 이 압축을 풉니다.
2. 기존 GitHub의 PWA 폴더로 들어갑니다.
3. index.html, manifest.webmanifest, sw.js, icons 폴더를 업로드하여 교체합니다.
4. Commit changes를 누릅니다.
5. Vercel 자동 배포가 끝날 때까지 기다립니다.
6. PC와 갤럭시에서 같은 이메일로 회원가입/로그인합니다.

주의
- 회원가입 후 이메일 인증 링크를 눌러야 로그인됩니다.
- Secret key나 service_role key는 이 파일에 들어있지 않습니다.

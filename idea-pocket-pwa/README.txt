Idea Pocket PWA — Ctrl+V 업데이트

업데이트 내용
- 아이디어 등록 화면에서 복사한 이미지 Ctrl+V 붙여넣기
- 복사한 텍스트를 메모에 붙여넣기
- 이미지 파일 드래그앤드롭
- 데스크톱 PWA 설치 지원
- 앱 바로가기: 아이디어 등록 / 아이디어 찾기

GitHub 업데이트
1. 기존 PWA 폴더 안의 index.html, manifest.webmanifest, sw.js를 새 파일로 교체
2. icons 폴더도 함께 교체
3. Commit changes
4. Vercel 자동 재배포 대기

PC에서 사용
1. Edge에서 Vercel 주소 접속
2. 오른쪽 위 … → 앱 → 이 사이트를 앱으로 설치
3. 작업 표시줄 또는 바탕화면에 고정
4. 앱 실행 → 아이디어 등록 → 이미지 복사 → Ctrl+V → 메모 → 저장
